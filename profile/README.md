# BIH Center of Digital Health JupyterHub

User management and documentation for the JupyterHub instance at [dh-jhub.bihealth.org](https://dh-jhub.bihealth.org/), hosted on the [de.NBI Cloud](https://www.denbi.de/cloud) and operated by the [Health Data Group](https://www.hidih.org/research/health-data) of the [BIH Center of Digital Health](https://www.hidih.org/).

## Requesting access

Access is available to  eligibility, e.g. BIH and Charité members, their collaborators and students.

1. Email naveed.ishaque@bih-charite.de with your GitHub username and a one-line description of your intended use.
2. Accept the invitation to join this organisation.
3. Return to this page while signed in to GitHub. Members see a private landing page with instructions for accessing and using the Hub.
